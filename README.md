# Executive Pathways: website + mini-CRM (student project)

Student project, not an official TAPMI offering.

Read **GUIDE.md** first. Quick start:

    python -m venv .venv
    .venv\Scripts\activate        (Mac: source .venv/bin/activate)
    pip install -r requirements.txt
    python app.py                 (Mac: python3 app.py)

Open http://127.0.0.1:5001   CRM login: /admin/login   password: tapmi-demo
